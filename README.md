# 🥔 Lay's – Premium Chips & Snacks Website

A modern, responsive and visually engaging **Lay's Premium Chips & Snacks** e-commerce concept website, designed with a beautiful Neumorphism-inspired UI. Explore delicious flavors, browse snack collections, discover special offers, and enjoy an interactive shopping experience.

🔗 **Live Demo:** https://lays-psi.vercel.app/

---

## 📌 Project Overview

Lay's is a frontend-only e-commerce website concept inspired by the popular Lay's potato chips brand.

The project focuses on creating a premium online snack-shopping experience with an attractive interface, smooth interactions, product discovery features, and a responsive layout.

**Note:** This is an independent student/portfolio project. It is not affiliated with or endorsed by Lay's or PepsiCo.

## ✨ Key Features

- 🎨 **Modern UI Design** – Clean and attractive Neumorphism-inspired interface.
- 📱 **Fully Responsive** – Optimized for desktop, tablet, and mobile devices.
- 🥔 **Product Collection** – Explore different Lay's snack flavors.
- 🔍 **Product Search** – Search products by name or flavor.
- ↕️ **Product Sorting** – Organize products with sorting options.
- ❤️ **Wishlist** – Save favorite snack products.
- 🛒 **Shopping Cart** – Add products and manage cart items.
- 🌶️ **Flavor Categories** – Explore Classic, Tangy, Savory, Spicy, and Creamy flavors.
- 🎁 **Special Offers** – Discover sample discounts and snack bundles.
- ⭐ **Customer Reviews** – Display sample customer feedback.
- 📧 **Newsletter Section** – Interactive subscription interface.
- 💻 **Modern Layout** – Professional navigation, hero section, and footer.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layouts, responsiveness and UI design
- JavaScript – Interactive functionality and dynamic elements
- Vercel – Website deployment

## 🎨 Design Concept

The website follows a modern Neumorphism-inspired design approach, focusing on:

- Soft shadows and depth effects
- Clean product presentation
- Attractive color combinations
- Smooth interactive elements
- Modern typography
- User-friendly navigation

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd lays-website
```

**3. Open the project**

Open `index.html` in your browser or use the Live Server extension in VS Code.
